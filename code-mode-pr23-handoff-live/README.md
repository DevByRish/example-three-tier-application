# Contributing

Thank you for your interest in contributing to this project!

## Before Submitting a Pull Request

Please ensure that:

1. **Run relevant tests**: Execute all tests related to your changes to verify they pass and do not introduce regressions.
   ```bash
   npm test
   ```

2. **Preserve Unicode/emoji coverage**: Maintain or improve Unicode and emoji support in your changes. Ensure that:
   - Existing Unicode/emoji test cases continue to pass
   - Any new features that handle text input preserve proper Unicode/emoji handling
   - Character encoding is properly maintained throughout the codebase

These requirements help us maintain code quality and ensure the project remains robust and inclusive for all users.

Thank you for your contributions!
